## Installation

```bash
omarchy-theme-install github.com/mateCreations/omarchy-yerba-mate
```

Or manually:

```bash
git clone https://github.com/mateCreations/omarchy-yerba-mate \
  ~/.config/omarchy/themes/yerba-mate
```
